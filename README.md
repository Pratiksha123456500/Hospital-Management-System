# 🏥 Hospital Management System

A console-based application developed to manage hospital operations such as patient records, doctor information, and appointment booking.
The project stores data in a MySQL database and performs database operations using JDBC.
## 📌 Features

* Add new patients
* View all patients
* Search patients
* Delete patients
* Update patients
* Add new doctors
* View all doctors
* Search doctors
* Delete doctors
* Update doctors
* Book appointments
* View appointment details
* Delete appointments
* Update appointments
* Store and retrieve data using MySQL
* JDBC-based database connectivity

## 🛠️ Technologies Used

## 🗄️ Database

Database Name:

hospital_db

Main Tables:

* patients
* doctors
* appointments

The project uses JDBC to connect Java with MySQL for performing CRUD operations and appointment management.

## ▶️ How to Run

1. Clone the repository:
   git clone <repository-url>
2. Open the project in VS Code.

3. Import the MySQL JDBC Connector JAR.

4. Start the MySQL server (XAMPP or MySQL Server).

5. Create the hospital_db database and required tables.

6. Update the database credentials in DBConnection.java.

7. Compile and run the project.
